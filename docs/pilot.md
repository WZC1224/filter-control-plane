# 运营试用清单（1 人 · 主路径）

> 目的：验证 idea 假设「运营愿意换到新入口」  
> 时长：约 20–40 分钟  
> 角色：建议用 `operator`（管理员先在「用户」页开好）

## 试用前（管理员准备）

- [ ] 后端 `python main.py`、前端 `npm run dev`（或已部署地址）可访问
- [ ] `.env` 下游已配（`DOWNSTREAM=auto` + data818 双 Token）**或**接受 Mock 演示
- [ ] 在「用户」页创建试用账号：`role=operator`，把用户名/密码发给试用者
- [ ] （可选）准备一份 ≥500 行、目标国家区号正确的 `.txt`（真下游建单会扣费）

## 试用者步骤

### A. 登录与认路（3 min）

- [ ] 打开登录页，用下发账号登录（**不要**用文档里的默认 admin）
- [ ] 看侧栏：有概览 / 任务 / 新建 / 订单 / 价目 / 公告 / 账号
- [ ] 确认**没有**「用户」「系统」（operator 应看不到）
- [ ] 顶栏显示用户名与 `operator`

### B. 主路径：列表 → 新建 → 详情（10–20 min）

- [ ] 「任务列表」能打开；空列表时有「去新建」引导
- [ ] 「新建任务」：类型 / 国家下拉有数据
- [ ] 选类型后看到单价与数量区间提示
- [ ] 上传行数不足最小值时，页面有明确警告且无法提交
- [ ] （Mock）提交成功 → 跳详情或列表能看到新任务
- [ ] （真下游）若余额不足 / 国家不符，错误文案可读（非白屏）

### C. 取结果（5–10 min）

- [ ] 打开已完成任务详情
- [ ] 点下载（csv 或 txt），浏览器得到文件（非空白、非乱码 JSON）
- [ ] 进行中任务：下载按钮不可用或提示业务错误（非空白文件）
- [ ] （可选）导出剩余号：得文件或可复制 OSS 路径

### D. 账号（2 min）

- [ ] 「账号」页能改自己密码；改完需重新登录
- [ ] 看不到关单 / 退款 / 重试按钮

## 通过标准（门禁）

试用算通过，当且仅当：

1. A–C 主路径无阻塞（或仅「余额/无已完成单」类外部原因）
2. 反馈表填完
3. 「愿不愿继续用」不是无条件「否」——若否，把原因拆成下一轮任务

未通过 → 不进「可部署交付」大范围推广。
